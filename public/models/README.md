# Optional Track-A models

Drop any of these files here and the game uses them instead of the procedural warriors
(detected at runtime, per piece type; Red and Black share each file — only materials change):

`general.glb  advisor.glb  elephant.glb  horse.glb  chariot.glb  cannon.glb  soldier.glb`

Animation clips whose names contain **Idle**, **Move** and **Attack** are cross-faded (0.18 s).
For the cannon, an object whose name contains **Muzzle** marks where the shell leaves the barrel.
Models are normalised to ~1.25 units tall and ≤ 0.7 across, standing on the plinth.
